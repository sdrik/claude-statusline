---
description: Remove the statusline from your Claude Code settings
---

Run the bundled uninstaller (it is on your PATH because this plugin is enabled) and report its full output to the user:

```bash
statusline-uninstall
```

Let the user know the status line will disappear on the next status refresh, and that a customised `~/.claude/statusline-command.sh` (one that differs from the shipped script) is left untouched.
